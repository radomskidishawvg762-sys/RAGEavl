```powershell

```

前端常规检查（工作目录 `frontend`）：

```powershell
npm test -- --reporter=dot

```

原运行只读验收需要开发后端 :8000、Vite :5173；从 `frontend` 执行：

```powershell

```

完整流程先从项目根目录启动隔离服务，再从 `frontend` 执行脚本：

```powershell
.\.venv\Scripts\python.exe scripts/serve_review.py

node scripts/workflow-e2e.mjs
```

隔离服务要求 `TEST_DATABASE_URL` 与 `DATABASE_URL` 指向不同数据库，并拒绝未明确命名为 test 的目标；仅新增唯一命名的测试项目，不执行 reset。**完整流程不要与 PostgreSQL pytest 并行运行**，后者会清理专用测试库表。日志和报告均不包含连接密码或 API 密钥。
